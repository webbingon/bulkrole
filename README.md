# BulkRole

BulkRoleは、Discordにおいて、ユーザー名とロール名を対照させたリスト(CSVファイル)をもとに、一括で自動的にロールを付与することができるアプリです。

## インストール

1. [GitHub Releases](https://github.com/webbingon/bulkrole/releases) から `bulkrole-win32-x64-x.x.x.zip` をダウンロードする。
2. ZIP ファイルを解凍する。
3. フォルダ内の `bulkrole.exe` を実行するとアプリが起動します。画面の指示に従って設定してください。

なお、`bulkrole.exe` 単体ではなく、必ずZIPを解凍したフォルダ全体を保持した状態で実行してください。

## 使い方

ユーザー名とロール名を対応させたCSVファイルから、自動でユーザーにロールを付与します。

BulkRoleはCSVファイルを次のように扱います:
- 1列目はユーザーの名前、2列目はそのユーザーに付与したいロールの名前。
- ユーザー名は、ニックネーム (サーバー内の名前)、表示名、ユーザーネームの順に優先する。例えば、ニックネームが設定されておらず、表示名が設定されているユーザーの場合、ユーザー名には表示名を使用してください。
- 1行目は列のラベルを入力するため無視する。

CSVファイルは、例えば次のようになります:
```csv
ユーザー名,ロール名
webbingon,管理者
webbingon,モデレーター
hogehoge,メンバー
```

## 注意点

- BulkRoleはCSVファイルの文字エンコードについて、Shift-JIS・UTF-8 (BOMあり/なし) に対応していますが、まれに文字化けして読み込まれてしまう場合があります。この場合には、CSVファイルの文字エンコードを「UTF-8 (BOM無し)」として保存した上で、もう一度お試しください。
- 重複するユーザー名・ロール名・サーバー名が設定されないようにしてください。重複していた場合、その名前にIDが併記されます。例えば「初心者」というロールが2つ存在した場合、「初心者 (ID: XXXXXXXXXXXXXXXXX)」「初心者 (ID: YYYYYYYYYYYYYYYYY)」のように認識されます。
- Discord APIのレート制限のため、ロールを付与する件数が多い場合には時間がかかります。
